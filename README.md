# Bioinformatics Analysis of SKCM

R scripts and result files for the bioinformatics analysis in the manuscript (TCGA-SKCM / GEO validation / machine-learning risk model / single-cell / Mendelian randomization / immune infiltration).

## Repository Structure

- `rscripts/` - All R scripts (run in numbered order)
- `results/` - Result files of each analysis step (same numbering as scripts)

## Scripts

| Script | Content |
|--------|---------|
| r-00.rawdata.R | Download & preparation: TCGA-SKCM, GSE15605, GSE65904, GSE222446 (single-cell), MDGs |
| r-01.DEGs.R | Differential expression analysis (Control vs SKCM) |
| r-02.Hubgene.R | Hub-gene screening (Venn intersection) |
| r-03.Enrichment.R | GO / KEGG enrichment analysis |
| r-04.MR.r | Two-sample Mendelian randomization (eQTL-GWAS) |
| r-05.Unicox.r | Univariate Cox regression screening |
| r-06.Model101.r | Machine-learning model construction (101 combinations: Lasso / RSF / CoxBoost / GBM / StepCox; C-index comparison) |
| r-07.Riskmodel.r | Risk-score model construction (KM, ROC, risk plot) |
| r-08.Verify.r | Validation in GEO cohorts |
| r-09.independent.r | Independent prognostic analysis |
| r-10.clinic.r | Clinical correlation analysis |
| r-11.GSEA.r | GSEA (KEGG) between risk groups |
| r-12.cibersort.r | Immune-cell infiltration (CIBERSORT) |
| r-13.scRNA.R | Single-cell RNA-seq pipeline (QC -> normalization -> PCA -> UMAP -> annotation -> pseudotime -> CellChat) |
| r-14.IC50.r | Drug sensitivity (IC50) analysis |

## Data Sources

- TCGA-SKCM (expression FPKM/TPM + clinical): GDC portal (https://portal.gdc.cancer.gov), generated by r-00.rawdata.R
- GEO datasets: GSE15605, GSE65904 (bulk), GSE222446 (single-cell), via GEOquery / AnnoProbe
- eQTL: eql-a-ENSG... (expression QTL summary statistics); GWAS: finngen_R9_C3_MELANOMA (https://r9.finngen.fi)
- Large raw matrices (>100 MB, e.g. TCGA FPKM/TPM csv) and intermediate .Rdata/.rds objects are NOT included in this repository to keep the repo size reasonable; they can be regenerated with the scripts.

## Usage

Run the scripts in numerical order with R (>= 4.2). Each script reads from `results/00_rawdata` (or the previous step) and writes outputs to the corresponding numbered folder.

`sessionInfo()` output for each script is provided in `rscripts/sessionInfo.txt`.
